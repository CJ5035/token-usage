## 关键口径决策

1. **report-range-kpis 是通用全渠道 KPI 条**：显示当前 range 的 total_tokens/输入/输出/requests（近似加 `~`）/已知费用；title 聚合 cost_partial → codexCostUnavailable、请求近似 → codexApproxRequests，" · " join（简报逐字）。今日 windows 仍来自 report/windows。
2. **scope=all 响应隔离**：loadReportAll 追加第 7 个 Promise，解构为 `all`，仅 `renderReportTotals(all.totals)`；绝不写 state.data、不调 renderAll（保护统计页账号数据）。
3. **Codex tab 显隐**：由后端 list_channel_summary EXISTS 注入控制（T4 renderChannelTabs 不自行判断）；前端只保证渠道名映射与点击行为正确。
4. **单渠道概览**：codex channel-overview 提供显式 total_tokens（17 键 T2 聚合）→ 优先采用；其余渠道 `_totals_from_row` 无该键走原和式，行为不变。总 token 副行对 codex 显示 `输入 X · 输出 Y`（输入已含缓存读、输出已含 reasoning，拆分展示不再次相加）。
5. **无账号（codex）隐藏额度/账期卡**：现有接线已满足（zcode-quota 按 channel!==zcode 隐藏、cc-summary 按 isCc 隐藏、usage-blocks 由 renderQuotaSingle 空账号隐藏），不继承前 tab 内容；chSeq/allSeq 守卫保留。
6. **费用 NULL**：renderWindows（windows cost 可为 NULL 纯 Codex 窗口）、renderChannelTable（codex 行 cost=null）、renderOverview（codex total_cost_usd=null）、renderReportTotals 统一 fmtOptionalMoney → `—`；fmtMoney 本体不改；renderOverview 均值副行在 NULL 时显示 codexCostUnavailable 文案（不做 null/0 除法）。
7. **费用图**：后端 report_daily metric=cost 已省略 codex series 并带 unavailable_channels → 图表天然只渲染有已知费用数据源；`unavailable_channels` 非空且 metric=cost 时 stack 卡头 report-cost-hint 显示 codexCostUnavailable（data-i18n 随 applyLang 刷新）；空已知集走现有 noDataInRange 空态；不 reduce NULL。tokens/requests 模式 codex 照常；donut onClick 仍按原始渠道键切 tab。
8. **主题色**：亮 #0f766e / 暗 #2dd4bf（简报指定）；CH_COLOR 固定映射 `codex: "var(--ch-codex)"`（测试断言此字符串）。
9. **转义**：渠道 tabs 与明细表的渠道名插值补 escapeHtml（new labels 转义）；图表 legend 为 canvas 文本无需转义。
10. **DSH**：renderChannelTable dsh 仅今日行、wb-since 口径标注、单渠道 today_only 提示全部保留；不跨维度比较 DSH 缺失历史。
11. **边界**：不加新 i18n 键（renderReportTotals 全部复用现有键）；不改欢迎页/记录页；report-range-kpis 在 loadReportAll 失败路径保持旧内容（与 windows-bar 同生命周期）。
