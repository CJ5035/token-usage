## 1. 目标

远程登录状态与本地 Codex 可用性成为**两个独立条件**：`logged_in` 仍只表示远程账号；
未登录但本机有 Codex 数据（`source_found` 或 `has_data`）的用户直达仪表盘；
两者皆无才显示欢迎页。同步更新双语交付文案与 README。

## 2. 判定函数（逐字，简报固定）

```javascript
function canUseLocalCodex(st) {
  return !!(st.codex && (st.codex.source_found || st.codex.has_data));
}
```

单点消费，禁止复制条件：
- `checkState`：`!logged_in && !canUseLocalCodex(st)` → 欢迎页；`!logged_in && canUseLocalCodex(st)` → 隐藏遮罩 + `loadDashboard`；`codex.running` 时进入 `pollUntilIdle`（T4 已同时等待两处 running，完成自动刷新）。
- 欢迎页轮询（`showLoginOverlay` 内）：`st.logged_in || canUseLocalCodex(st)` 即进入面板。
- 登出 / 删除账号回调：全部退出/删除后仍经 `canUseLocalCodex` 判定，有本地 Codex 数据不回欢迎页。
- `startSync`：401 已被 catch 且 `pollUntilIdle` 无条件执行——按钮不会永久禁用，Codex 本地导入照常轮询至空闲（仅补注释固化契约）。
- `renderSyncBanner` 接受 codex 快照：Codex 导入期间同步指示条可见（"importing 状态可见"），两处调用点（renderAll / pollUntilIdle）传 `data.codex` / `st.codex`。
