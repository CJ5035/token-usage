# Bug 诊断报告：香槟金主题下多渠道图表辨识度不足

- **日期**：2026-09-11
- **状态**：已确认，待修复
- **严重级别**：P2 一般（影响数据阅读，不影响页面打开）
- **报告人**：Codex Agent（Bug Diagnosis Skill）

---

## 问题描述

用户反馈：使用香槟金 + 炭黑主题后，特别是多渠道图表不够清晰。

复现页面：`doc/20260911-香槟金炭黑配色演示.html`

## 环境信息

- **相关模块**：独立 HTML 配色演示页
- **相关区域**：分渠道消耗趋势、渠道占比图、图例
- **复现步骤**：打开页面，查看“分渠道消耗趋势”堆叠柱状图；对比图例与柱体色块，并观察占比 2%～4% 的小色块。

## 可能原因分析

| # | 原因 | 概率 | 理由 |
|---|---|---|---|
| 1 | 同色系明度接近，且相邻色块没有分隔线 | 高 | 图表色值集中在金、铜、银的暖中性色，堆叠边界只依靠色差识别；炭黑背景会进一步放大中间色阶的混淆。 |
| 2 | 图例与堆叠柱的数据项数量不一致 | 高 | 图例包含 `commandcode`，但柱状图第 172 行只有 5 个 `rect`，没有对应的绿色/sage 色块。 |
| 3 | 小占比渠道的几何宽度过小 | 高 | 2%～4% 的数据段在 200px 高的柱体中只有约 2～12px，缺少边框时很难定位。 |
| 4 | 图表承担了过多“品牌色”职责 | 中 | 香槟金作为界面主色很高级，但不适合作为所有渠道的分类色；用户需要的是可区分性，而非统一色相。 |
| 5 | 图表缺少悬浮提示或直接标注 | 低 | 当前是静态演示，鼠标悬浮只能改变透明度，没有数值或渠道名称辅助确认。 |

## 验证动作

### 针对原因 1：同色系色块边界不明显

- **验证方式**：对比页面 CSS 变量和图表矩形填充色。
- **位置**：`doc/20260911-香槟金炭黑配色演示.html:10-25`、`:172`
- **具体操作**：临时为每个 `.bar` 增加 `stroke="#11100f" stroke-width="2"`，重新渲染页面。
- **预期结果**：如果边界明显改善，则说明主要问题是相邻色块缺少结构性分隔，而不是背景色本身。

### 针对原因 2：图例和柱体数量不一致

- **验证方式**：逐项对比柱体和图例。
- **位置**：`doc/20260911-香槟金炭黑配色演示.html:172`、`:175`
- **具体操作**：统计第 172 行的 `rect` 数量和第 175 行的 `legend-item` 数量，并按渠道名称建立一一映射。
- **预期结果**：当前应得到 5 个柱体色块、6 个图例项，其中 `commandcode` 无柱体对应项。

### 针对原因 3：小占比色块过窄

- **验证方式**：查看第 172 行各矩形的高度，并在 1250px 以下视口再次渲染。
- **位置**：`doc/20260911-香槟金炭黑配色演示.html:166-174`
- **具体操作**：分别在 1600px 和 1120px 宽度打开页面，观察高度为 2px～12px 的数据段是否还能被定位。
- **预期结果**：窄视口下小色块辨识度进一步下降，说明需要分隔线、标签或悬浮提示兜底。

## 调用链与依赖分析

这是一个无后端依赖的静态演示页，调用链如下：

```text
CSS 颜色变量 :10-25
  → .bar / .grid-line 样式 :79-83
    → 堆叠柱 rect 填充 :172
      → 图例颜色点与渠道名称 :175

CSS 颜色变量 :10-25
  → .donut conic-gradient :111
    → 环形图 :179
      → 环形图图例 :180
```

关键依赖节点：

- **上游**：主题变量和静态演示数据。
- **出错节点**：第 172 行的堆叠柱颜色与第 175 行的图例映射。
- **下游影响**：趋势图的渠道识别，以及用户对小占比渠道的判断。
- **影响范围**：只影响本演示页，不影响 `app/web/app.js` 或现有业务图表。

## 边缘情况检查

| 维度 | 场景 | 当前行为 | 是否有问题 | 建议 |
|---|---|---|---|---|
| 数据边界 | 渠道占比 2%～4% | 色块只有约 2～12px 高 | 是 | 增加分隔线，并提供悬浮提示或旁侧明细。 |
| 数据边界 | 渠道数量增加到 6 个 | 图例有 6 项，但柱体只有 5 段 | 是 | 统一维护渠道数据数组，保证柱体和图例同源。 |
| 视觉对比 | 暖金、铜、银相邻 | 边界只依靠填充色 | 是 | 图表分类色使用高区分度色相，品牌金只保留给主渠道/选中态。 |
| 响应式 | 视口接近 1120px | 图表区域变窄，小段更难识别 | 是 | 保留最小图例间距，或在窄屏切换为渠道明细列表。 |
| 交互反馈 | 鼠标悬浮色块 | 只降低透明度 | 轻微 | 增加渠道名、Token 数量和占比提示。 |
| 空值处理 | 某渠道无数据 | 静态演示暂无空值分支 | 不确定 | 真实接入时隐藏零值图例，避免出现无意义色点。 |

## 总结与建议

最可能的根因是“同色系分类色 + 无色块分隔 + 图例映射不完整”叠加造成的辨识度下降。建议下一步采用三层修正：

1. 先修正图例与柱体的一一对应关系，补齐 `commandcode` 或移除无数据图例。
2. 为堆叠色块增加 1～2px 深炭黑分隔线，提升边界清晰度。
3. 保留香槟金作为界面品牌色，但将图表分类色改成“香槟金、鼠尾草绿、石板灰、铜红、酒红、象牙白”的高区分度组合。

本次仅完成诊断，尚未修改演示页。
