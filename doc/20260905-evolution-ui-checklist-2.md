## ① 未登录行形态：徽标 + 按钮组（§2.5① + §5 备注 8/10）

**操作**：对账号 A 执行「退出登录」（见 ④ 步骤），停留在设置页观察 A 行。

- [ ] A 行出现「未登录」徽标（zh）/「Not logged in」徽标（en），样式为红系 `.badge.no`（--danger-soft 底/--red 字，style.css:337）
- [ ] A 行的 `ur-ws` 行**不再出现**「· 已登录」后缀（徽标已承载状态，无双重标注）
- [ ] A 行按钮组为 **登录 / 重命名 / 删除**（§5 备注 8 顺序：危险动作「删除」置末、红色样式）
- [ ] A 行**不出现**：重新登录 / 退出登录 / 切换 按钮
- [ ] **活跃指针指向未登录行的形态**（可通过单账号登出构造）：该行同样渲染 登录/重命名/删除 + 未登录徽标，不出现「当前」徽标、无高亮态
- [ ] **§5 备注 10 补项**：点开顶栏右上角用户菜单——**不出现**未登录项（菜单仍只列已登录账号）；若全部已登出，菜单显示空态文案（noUsers），与设置页未登录行并存为既定口径（§5 备注 9）

## ④ 多账号两步删除（§2.5④）

**前置**：A、B 均已登录，A 为活跃。

**操作**：对 A 先退出、再删除。

- [ ] 点击 A 行「退出登录」→ 弹确认框，文案为疑问句且**无红色危险警示**：zh「将退出「A」，仅清除登录凭证，本地用量数据保留。确定？」/ en "Sign out \"A\"? This only clears the credential — local usage data is kept. Continue?"
- [ ] 确认后 A 行变为未登录形态，**「删除」按钮出现**（第一步完成）
- [ ] 点击 A 行「删除」→ 确认后 A 行消失，B 及其余账号数据/卡片不受影响
- [ ] 退出 A 后概览页 A 卡片即时移除（overview 按 has_token 过滤口径），B 卡片仍在

## ⑤ 单账号形态：退出 → 管理本地数据 → 直接可删（§2.5⑤）

**前置**：仅剩 1 个已登录账号 B（可先删掉 A 构造）。

**操作**：退出 B → 欢迎遮罩出现 → 点「管理本地数据」→ 在设置页删除 B。

- [ ] 退出 B 后欢迎遮罩出现（remaining==0 回遮罩闭环，§5 备注 7）
- [ ] 点「管理本地数据」后 B 行直接渲染 **删除** 按钮（单账号形态无需"再登出一次"的两步操作——活跃指针虽指向 B，行按未登录矩阵渲染）
- [ ] 删除 B 后设置页列表空/仅剩种子行，界面无异常

## ⑥ 退出后重登数据仍在 + 串号回归（§2.5⑥ + §5 备注 6 观察点）

**操作**：账号 B（有历史用量）退出 → 重新登录 → 检查数据；多账号下定向登录检查串号。

- [ ] B 退出后再从其未登录行「登录」→ 授权完成 → **观察点（§5 备注 6）：设置页 B 行即时变为已登录态**（startLoginWatch 短轮询兜底生效，无需手动刷新）
- [ ] B 重登后打开记录/统计页：**历史用量记录仍在**（仅清凭证、数据保留）
- [ ] **串号回归**：A、B 两行均未登录（或 A 已登录非活跃）时，点 **B 行**的「登录」→ 授权后凭证落在 **B** 行、活跃指针切到 B，查看的统计/记录是 B 的数据；A 行凭证与数据不变
- [ ] 欢迎页「立即登录」兜底路径（无 body POST /api/relogin）仍可用：遮罩上点立即登录能正常打开授权页
