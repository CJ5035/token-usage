## 关键口径决策

1. **HTML 骨架**：逐字采用简报骨架（section class="codex-stats"，外层不加 card，避免外层 card 再嵌 KPI cards 的双层卡壳）；唯一偏差：chart-box 内补 `<div class="zcode-chart-empty" id="codex-trend-empty" hidden></div>` 空态占位——简报正文要求"无数据销毁图表并显示空态"，且 zcode/claudecode 三图均为同一空态机制。
2. **KPI 构成**（总量行 totals / 今日行 today，各 6 卡）：请求（近似标记）、总 Token、输入(含缓存)、输出、平均输出速度（缺失 `—`+codexSpeedUnavailable tooltip）、费用（恒 `—`+codexCostUnavailable tooltip，NULL 不渲染为 0）。今日行复用同一组既有标签键（简报 7 键未含今日专属键，DSH 双行先例）。
3. **表格列**（两表一致口径）：渠道(provider_id)、请求、输入、输出、总Token、平均速度；模型表多一列模型（provider_id + model）。列清单严格按简报"请求、输入、输出、total_tokens、avg_tps"，无费用列（无费用线同理由）。
4. **近似请求数**：`request_count_exact=false` 时 KPI 与两表请求值加 `~` 前缀，span 携带 title+aria-label=codexApproxRequests；true 时不加标记。
5. **空态/错误态**：仅 `db_found=false`（无 source 目录且镜像表无数据）显示 codex-missing 并隐藏 KPI/表格/图；`source_found=false,has_data=true` 照常展示历史；`source_found=true,has_data=false` 展示零 KPI（表体"暂无数据"行、图空态）。fetch 失败：显示 codex-error（textContent，独立状态条）且保留旧数据（不清 codexSummaryLast、不隐藏区块）；成功路径隐藏 codex-error。
6. **转义**：provider_id/model/未知模型文案一律 escapeHtml（模型图标 alt 由 modelIcon 内部转义）；错误条用 textContent。
7. **loadCodexSummary**：简报骨架逐字（seq 守卫 + range 键校验双保险，篡改 range 的旧响应不覆盖新范围）；请求 URL 用 encodeURIComponent。
8. **chartCodexTrend**：固定 daily7 近 7 日两 series（total_tokens 实线 / request_count 虚线右轴）；全零或空 → destroy + 空态；无费用线；noAnim 参数入 rerenderCharts 主题重渲链。
9. **pollUntilIdle**：同时等待 `st.progress.running` 与 `st.codex.running` 都空闲才恢复按钮并刷新；catch 分支也释放两个按钮（拉状态失败不再卡死手动刷新）；空闲分支失效 channelTabsCache（后台导入可能新增渠道数据，60s 缓存改为立即重拉）后 `await loadDashboard()`（home/stats 主区）+ refreshCodexVisible 分派（stats→loadCodexSummary；home→loadDashboard(true)；records→Promise.all(loadRecords/loadSessions)；其他页仅更新状态）。单 2.5s timer 复用 state.syncTimer，完成/失败清理；不另建无界轮询，静止页面增量仍走 restartAutoSync 现有间隔。
10. **updateStatsScopeHint**：localHas 并入 Codex totals 检测（total_tokens>0 或 request_count>0）；statsScopeHint 双语文案补 Codex 提及，主区解释语义保留。
11. **边界**：不加 CH_COLOR.codex / --ch-codex（T5）；不改欢迎页文案（T7）；不改记录页行为（交付二）；不把 Codex totals 写入 state.data；设置页/账户总览不加 Codex 控件。
