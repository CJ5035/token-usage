## 关键口径决策

1. **NULL 不是 0**：`_win_codex` 有数据时 `cost=None`、`cost_available=False`、`cost_partial=True`；空窗口 cost=0.0。`_win_merge` 按简报代码：known=各来源 requests>0 且 cost 非空的集合，known 空但有用量 → cost=None，全空 → 0.0。混合来源保留其他来源已知小计并标 cost_partial。
2. **request_count_exact**：codex 行 = 范围内 `COUNT(*)>0 AND MIN(request_count_exact)=1`（token_count 兼容模式记录即 false）；summary 顶层取 `_win_codex` 同口径（范围内贡献记录事件模式，空范围 false）。其余来源（opencode/zcode/claudecode）请求数为精确 COUNT(*)，窗口行 request_count_exact=requests>0；混合窗口按简报 `all(...)` 收敛。summary 顶层不混入其他来源（Codex 专属视图）。
3. **range 白名单**：`today/yesterday/7d/30d/all`，非法值在 `_codex_summary_payload`/`_dashboard_all_payload` 入口回落端点默认（summary=30d，scope=all=today），不拼接 SQL。
4. **读取防抖**：仅 Codex/all 查询触发 `_maybe_trigger_codex_import()`（60s 防抖、后台线程、请求不等待）；专属 zcode/claude/bai 等渠道与 dashboard 无 scope 不触发。
5. **导入状态**：`_codex_import_lock` 非阻塞单飞；`running` 全程置位；只有"无告警的完整成功"清 `last_error`（commit_codex_batch 成功批会清空 → 同步末尾按本轮告警恢复旧错误，不以部分成功覆盖）；可跳过告警保留错误计数（warning_count 由批次累计）与旧错误文案；无变化成功扫描也推进 `last_import_at`；仅数据变化（inserted>0）加 revision；单批失败回滚不阻塞其余批次。
6. **hourly/channel_trend 兼容**：旧形状（labels/series；input/output）保留，新增固定字段与 buckets，现有旧用例继续通过。
7. **dashboard**：`scope=all` 返回 scope/range/totals=report_totals(range)/today/today=report_totals(today)/exchange_rate/codex 状态，不伪装 active account（无 account/quota 键）；DSH 仅 range=today 并入 totals/today（tokens=input+output+reasoning，requests/cost 不虚报）。无 scope 分支保持原语义，仅追加 `scope="account"` 与 `codex` 状态。
8. **登录独立**：`/api/codex/summary` 与 scope=all 不依赖任何已登录账号；`/api/sync` 保持登录守卫与 401 语义不变，piggyback 在账号同步完成后执行。
9. **不新增** `/api/codex/records` 公共端点（交付二 T6）。

## 实现期补充决策（绿灯后定稿）

10. **游标 updated_at 兜底**：`_sync_codex_local` 在提交前发现批次 progress 缺
    `updated_at` 时补当前 UTC 时刻（T2 `commit_codex_batch` 原样落库，不在 db 层改）。
11. **last_import_at 双来源**：state/summary 的 `last_import_at` 优先取镜像表
    `MAX(synced_at)`（有数据即可观测），空库回落导入状态表的最近扫描时刻；
    `has_data` 严格按镜像表判定（空库但扫描过 ≠ 有数据）。
12. **非 Codex 来源窗口行**：`_win_records/_win_zcode/_win_cc` 补齐 11 键时
    `request_count_exact = requests > 0`（COUNT(*) 精确）、`cost_available = requests > 0`
    （费用数值已知，BAI/ZCode/CC 为估算但非 NULL）；混合窗口按简报 `all(...)` 收敛，
    只要 Codex 含 token_count 兼容模式记录即整体 false。
