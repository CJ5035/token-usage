## 排序说明

预估严重等级优先（三项均 P2，无 P1——第二轮已修复唯一的 P1）；同等级内按影响面×修复收益：
- #7 影响面「高」：所有以 ZCode/DSH/CC 为主渠道的用户（本项目开发库自身即此形态）统计页主区**永远**全 0 空白；每天零点后/DSH 就绪前首页同现。矛盾+荒谬数据（↑100%）直接动摇数据可信感。「更好的显示方式」的核心答案。收益「高」：空态策略统一 + 一行口径提示即可。
- #8 影响面「高」：Windows 高 DPI 缩放是出厂默认（125%/150%），受影响用户远多于 100%；三处错乱一揽子 CSS 级修复收益高。单处损伤略低于 #7。
- #9 一致性问题：泄漏 tooltip 高频可见（顶栏/侧栏每页都在），但悬停才感知；口径错乱路径窄（进过统计页+回首页+切语言）。修复机械、风险低。
