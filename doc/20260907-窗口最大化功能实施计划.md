# 窗口最大化功能 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or inline execution to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 frameless 主窗口增加最大化/还原能力，保证不遮挡任务栏、最大化时拖动/托盘/图表行为全部正确。

**Architecture:** 后端 `WindowApi` 新增 `toggle_maximize()`（以 WinForms `WindowState` 为单一事实源，pywebview 封装的 `maximize()`/`restore()` 内部 Invoke 到 UI 线程）；`LocationChanged` 事件动态维护 `MaximizedBounds` 为当前屏工作区（防无边框窗口最大化遮挡任务栏、覆盖多显示器与 Win+Up 系统旁路）。前端标题栏加最大化按钮，图标状态在 window resize 时以 `outerWidth/outerHeight` vs `screen.availWidth/availHeight` 实时推断（不记标志，系统旁路可自愈）；resize 监听补全首页 report-all 分支的 3 张图表。

**Tech Stack:** Python 3.12 (pyenv-win) + pywebview (winforms/WinForms via pythonnet) + ctypes Win32；前端原生 JS + Chart.js (`responsive:false`)；测试 pytest（后端 mock + 前端源码级静态断言，参照 `tests/test_i18n_consistency.py` 手法）。

## 背景与风险结论（Spec）

主窗口 `frameless=True`（[app/main.py:500](../app/main.py)）→ pywebview winforms 后端设 `FormBorderStyle.None` → 无系统边框：不能拖边缘缩放、无系统最大化按钮，`resizable` 参数被覆盖。三轮 review 确认的事实与必须处理的坑：

1. **任务栏遮挡**：pywebview `maximize()` 仅设 `WindowState=Maximized`，对 `MaximizedBounds` 零处理；无边框窗口最大化默认铺满全屏覆盖任务栏。方案：`LocationChanged` 动态设 `MaximizedBounds = Screen.FromHandle(Handle).WorkingArea`。
2. **系统旁路**：窗口样式已含 `WS_MAXIMIZEBOX`（`_enable_taskbar_minimize` docstring 实测）→ Win+Up 可绕过前端按钮最大化。对策：前端不记状态标志，resize 时实时推断；后端 `move_by` 直接查 `native.WindowState`。
3. **托盘冲突**：`TrayIcon._show` 无条件 `win.restore()`（= `WindowState.Normal`），最大化→托盘→显示会丢最大化状态。改为仅 Minimized 时 restore。
4. **图表错乱（唯一真实的页面错乱）**：全部图表 `responsive:false`；resize 监听 `page-home` 分支只覆盖 `cToday`，而同页 `report-all` 分支（全部渠道视图）的 `cStack`/`cDonut`/`cHourly` 未覆盖——默认视图最大化即 3 图缩在容器一角。修复：补 3 行 `safeResize`（`report-all`/`report-single` 互斥 hidden，`safeResize` 的 `clientWidth>0` 保护自动跳过不可见分支）。
5. **CSS 布局无风险**：`grid repeat(N, 1fr)` + flex、无 `max-width`，拉宽只变稀不错位；spark 为 SVG `viewBox` 自适应。
6. **i18n**：新按钮 tooltip 走 `data-i18n-title` 机制；图标切换必须同步 `data-i18n-title` 属性，否则 `syncI18nTitles` 切语言后 tooltip 与状态不符。

```python
def _setup_maximize_bounds(win) -> None:
    """无边框窗口最大化支持: 动态维护 MaximizedBounds 为窗口当前所在屏工作区.

    FormBorderStyle.None 的窗口最大化时 WinForms 未设 MaximizedBounds, 按整个
    屏幕计算最大化区域, 会覆盖任务栏. 位置变化 (LocationChanged) 时按当时
    所在屏刷新, 保证多显示器下拖到任一屏后最大化 (标题栏按钮或 Win+Up)
    都不遮挡任务栏. WinForms 事件在 UI 线程触发, 与 js_api 工作线程无交叉.
    """
    try:
        from System.Windows.Forms import Screen  # pythonnet, 随 pywebview winforms 后端加载

        def _refresh(_sender=None, _args=None) -> None:
            try:
                native = win.native
                native.MaximizedBounds = Screen.FromHandle(native.Handle).WorkingArea
            except Exception:  # noqa: BLE001
                pass

        _refresh()
        win.native.LocationChanged += _refresh
    except Exception:  # noqa: BLE001
        pass
```

3b. `WindowApi` 内 `minimize` 方法之后插入：

```python
    def toggle_maximize(self) -> bool:
        """最大化/还原切换 (自定义标题栏按钮).

        状态以 WinForms WindowState 为单一事实源: Win+Up 等系统入口与按钮
        走同一状态, 前端按钮图标据此推断, 后端不另记标志. maximize/restore
        由 pywebview 内部 Invoke 封送到 UI 线程, js_api 工作线程不直接写
        native 属性 (WinForms 跨线程写会抛 InvalidOperationException).
        """
        if not self._win:
            return True
        try:
            if str(self._win.native.WindowState) == "Maximized":
                self._win.restore()
            else:
                self._win.maximize()
        except Exception:  # noqa: BLE001
            pass
        return True
```

```javascript
/* 最大化按钮状态: 不记标志, 每次 resize/初始化后以窗口实际尺寸推断
   (Win+Up 系统旁路最大化也被覆盖); 切换图标时同步 data-i18n-title 属性,
   保证 syncI18nTitles 切语言后 tooltip 仍与真实状态一致. */
const MAX_SVG = '<svg viewBox="0 0 12 12"><path d="M2.5 2.5h7v7h-7z"/></svg>';
const RESTORE_SVG = '<svg viewBox="0 0 12 12"><path d="M3.5 4.5h5v5h-5z"/><path d="M4.5 4.5v-2h5v5h-2"/></svg>';
function isWindowMaximized() {
  return Math.abs(window.outerWidth - screen.availWidth) <= 4
    && Math.abs(window.outerHeight - screen.availHeight) <= 4;
}
function syncMaxBtn() {
  const btn = $("tb-max");
  if (!btn) return;
  const max = isWindowMaximized();
  btn.innerHTML = max ? RESTORE_SVG : MAX_SVG;
  btn.setAttribute("data-i18n-title", max ? "restore" : "maximize");
  btn.title = t(max ? "restore" : "maximize");
}
```
